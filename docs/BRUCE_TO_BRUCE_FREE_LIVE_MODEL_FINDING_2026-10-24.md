# Free live multimodal candidate — October 24, 2026

Recommendation for a controlled adult business-development prototype: Gemini Live API, model gemini-3.8-live, subject to actual account availability/quota. Not yet integrated or tested with Sage. This is a candidate, not a claim of Gemini-app equivalence, unlimited free usage, private processing or public-launch readiness.

Verified official sources:
- https://ai.google.dev/gemini-api/docs/live-api — voice, image and text streams, spoken responses, interruptions, tools; images at up to one frame/second. Developer API can power a custom Sage interface; this is not embedding the Gemini consumer app.
- https://ai.google.dev/gemini-api/docs/pricing — Gemini 3.8 Live standard input/output listed free of charge on Free Tier; Google Search grounding marked supported. Recheck live pricing before implementation.
- https://ai.google.dev/gemini-api/docs/rate-limits — actual project limits in AI Studio, capacity not guaranteed. No blanket free production/continuous-use promise.
- https://ai.google.dev/gemini-api/terms — unpaid inputs/outputs may improve Google products and receive human review; do not submit sensitive, confidential or personal information. Age 18+, API clients not directed toward or likely accessed by under-18s; developer business/professional use; regional restrictions apply. This constrains the broad personal/family companion vision and requires scope review before public integration.
- https://ai.google.dev/gemini-api/docs/live-api/ephemeral-tokens — backend should issue short-lived constrained tokens; never expose a permanent API key in the public static page.
