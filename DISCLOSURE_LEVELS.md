# Disclosure Levels

Every substantial claim, component, and release must use one evidence label.

- **Implemented**: present in code or documentation, not necessarily tested.
- **Experimentally verified**: tested against stated acceptance criteria with reproducible evidence.
- **Prototype**: functional exploratory implementation not approved for production.
- **Simulation**: behavior demonstrated only in a simulated environment.
- **Proposed**: specified but not implemented.
- **Speculative**: conceptual or dependent on unresolved science, engineering, policy, or evidence.

## Rules

1. Never present proposed, simulated, or speculative work as deployed fact.
2. Record the test, data, version, environment, and limitations behind a verified claim.
3. Downgrade a label when evidence becomes invalid or non-reproducible.
4. Claims about consciousness, sentience, personhood, safety, alignment, or moral status require independent review and must state uncertainty.
5. Public summaries must preserve the same evidence level used internally.
